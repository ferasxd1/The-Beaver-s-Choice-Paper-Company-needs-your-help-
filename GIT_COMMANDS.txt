=================================================================
خطوات رفع المشروع على GitHub
=================================================================

افتح Terminal في مجلد المشروع ونفذ الأوامر التالية:

# 1. تهيئة Git (إذا لم يكن موجود)
git init

# 2. إضافة جميع الملفات
git add .

# 3. عمل Commit
git commit -m "Initial commit: Beaver's Choice Multi-Agent System"

# 4. ربط المشروع بـ GitHub
git remote add origin https://github.com/ferasxd1/The-Beaver-s-Choice-Paper-Company-needs-your-help-.git

# 5. رفع الملفات
git branch -M main
git push -u origin main

=================================================================
ملاحظات مهمة:
=================================================================

1. ملف .env لن يُرفع (محمي بواسطة .gitignore)
2. ملف .db لن يُرفع (محمي بواسطة .gitignore)
3. كل الملفات المهمة للمشروع سترفع
